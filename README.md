# Fundamentos de Programación C# – Proyectos Académicos y Personales

Este repositorio contiene **ejercicios y proyectos realizados durante mi formación en Desarrollo de Aplicaciones Web (DAW)** y programación en C#. Incluye teoría, prácticas diarias y proyectos personales completos, reflejando la aplicación práctica de los conocimientos adquiridos.

Se destacan aspectos como **orientación a objetos, manejo de variables y estructuras de control, gestión de errores y lógica de negocio**, utilizando **Visual Studio Code** como entorno de desarrollo principal.

---

## 🌟 Tecnologías y herramientas

- **Lenguaje:** C#  
- **Conceptos clave aplicados:**  
  - Orientación a objetos (clases, herencia, polimorfismo)  
  - Manejo de variables y estructuras de control (loops, condicionales)  
  - Gestión de errores y excepciones  
  - Lógica de programación y estructuras de datos  
- **Entorno de desarrollo:** Visual Studio Code  
- **Control de versiones:** Git y GitHub

## 🚀 Proyectos Personales

Carpeta con **aplicaciones completas** en C#, que demuestran la implementación práctica de conceptos avanzados:

[📂 PROYECTOS PERSONALES](https://github.com/GemaRJ/Fundamentos-de-Programacion-Csharp/tree/main/Proyectos%20Personales)

### Proyectos incluidos

1. **Blackjack** – Juego de cartas implementado en consola, que aplica lógica de juego y control de errores.  
2. **Calculadora** – Aplicación de consola para realizar operaciones matemáticas básicas con manejo de errores.  
3. **Entrenamiento** – Programa para registrar y gestionar rutinas de entrenamiento, aplicando **POO y manejo de datos**.  
4. **Ficheros de Contar Palabras** – Ejercicios de control de ficheros y lectura/escritura de datos.  
5. **Gestor de Tareas** – Sistema para organizar tareas, fechas de entrega y prioridades, reforzando **POO y estructuras de datos**.  
6. **Herencia con Coches** – Proyecto que demuestra el uso de **POO avanzada y herencia** en C#.

> Todos estos proyectos muestran **creatividad, planificación y capacidad de implementar programas funcionales y estructurados en C#**, aplicando buenas prácticas de desarrollo y aprendizaje progresivo.
